# Trình độ xuất phát: mới với Unity, quen Git cơ bản

Người học tự nhận mới với Unity (chưa từng dùng Editor) nhưng đã quen Git ở mức fetch/checkout/nhánh, và hiện đang ở nhánh `Fix/HUD-ThanhMau-BossBar` của repo `IronWasteland` (lúc ghi bản đầu là `SuaLoi_Coop`). Điều này đặt mức sàn cho mọi buổi sau: phải giải thích khái niệm editor (Scene, Prefab, ScriptableObject, Play Mode) chứ không thể nói tắt, nhưng **không cần** giảng lại Git.

**Implications**: bài đầu phải là bản đồ dự án + thuật ngữ, không phải "Unity là gì". Đọc code là kỹ năng cần dạy riêng (khối `<summary>` đầu class, luồng input → skill → damage). Chưa có bằng chứng nào về khả năng đọc kiến trúc, nên bài 02 nên là đọc một file C# thật thay vì thêm khái niệm mới.
